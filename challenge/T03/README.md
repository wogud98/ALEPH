# 사진 한 장, 글자 한 줄

사진을 고르고, 한 줄을 쓰고, PNG로 저장하는 로그인 없는 이미지 문구 편집기입니다. 보안 수칙, 학습 기록, 공지, 다짐 등 어떤 문구에도 쓸 수 있게 만들었습니다.

- 결과물: https://wogud98.github.io/ALEPH/challenge/T03/
- 소스: https://github.com/wogud98/ALEPH/tree/main/challenge/T03

## 데이터 처리 점검표

| 브라우저 안에서만 처리하는 것 | 저장하거나 보내지 않는 것 |
|---|---|
| 사진과 글자 (서버로 전송하지 않음) | 사진 원본 (템플릿에도 저장하지 않음) |
| 내 템플릿: 비율, 글자, 글꼴, 크기, 색, 효과, 정렬, 위치, 배경색 (`localStorage`) | 원본 사진의 촬영 정보·위치 정보 (PNG를 새로 그려 만들기 때문에 들어가지 않음) |

## 구성

- `index.html` 하나로 동작 (외부 파일 없음, 글꼴만 Google Fonts·jsDelivr)
- 사진: 선택 또는 끌어다 놓기 (PNG·JPEG, 20MB 이하), 사진이 없으면 배경색으로 채움
- 화면비: 1:1 정사각, 4:5 세로, 9:16 스토리 (가운데 기준으로 채우고 넘치는 부분은 잘림)
- 글자: 문구, 글꼴, 크기, 색, 효과(없음·그림자·테두리), 정렬, 가로·세로 위치와 글자 영역 너비 슬라이더 (영역을 넘으면 자동 줄바꿈)
- 템플릿: 예시로 시작하기, 내 템플릿 저장·덮어쓰기, JSON 내보내기·가져오기 (가져올 때 파일 전체를 먼저 검사하고 하나라도 틀리면 아무것도 바꾸지 않음)
- 결과물은 "PNG로 저장" 버튼으로 내려받음
