# 천궁 방공전

천궁 발사대로 순항미사일, 탄도미사일, 자폭드론을 요격해 청와대와 ALEPH 본부를 지키는 브라우저 8비트 지대공 방어 게임입니다.

- 결과물: https://wogud98.github.io/ALEPH/challenge/T02/
- 소스: https://github.com/wogud98/ALEPH/tree/main/challenge/T02

## 게임 규칙

| 항목 | 내용 |
|---|---|
| 목표 | 20초를 버티면 라운드 클리어. 5라운드마다 보스, 16라운드는 분신 5기 중 본체 1기를 1발로 맞히는 이벤트 |
| 방어지역 | 청와대·ALEPH 본부 각 체력 2 (맞은 직후 0.8초는 추가 피해 없음). 두 곳이 모두 파괴되면 패배 |
| 탄약 | 10발, 1.6초마다 1발 충전. 발사대 위쪽에서 가장 가까운 목표를 자동 조준 |
| 점수 | 1발 발사 비용 100만 달러(50점)가 점수에서 빠짐. 2라운드 이상에서 시작하면 연습 판으로 최고 기록에 반영되지 않음 |
| 난이도 | EASY / HARD, 시작 라운드 선택 가능 |

## 구성

- `index.html` 하나로 동작 (외부 파일·외부 요청 없음, 그림과 소리 모두 코드로 생성)
- 조작: `←` `→` 또는 `A` `D` 이동, `Space` 발사, `P` 일시정지, `Enter` 시작·다음 라운드, `R` 다시 시작, `M` 소리 끄기
- 접근성: "소리 끄기", "흔들림·깜빡임 끄기" 버튼 (기본값은 시스템의 움직임 줄이기 설정을 따름)
- 기록·검사 패널: 실행 상태(오류·창 크기·가로 넘침), 스페이스 연타 검사(`T` 키), 난이도 실험값, 최근 80판 기록 표 복사(마크다운), 저장 초기화
- 기록과 설정은 이 브라우저의 `localStorage` 에만 저장하며 서버로 보내지 않음
