# 대화가 끊겨도 이어지는 프로젝트 — 두 AI 이어받기

T04 달러 환율 장부의 실제 버그 하나를 AI A가 절반 고치고 멈춘 뒤, 다른 서비스의 AI B가 **저장소와 인수인계 문서만** 받아 끝냈습니다. 대화 전문은 넘기지 않았습니다.

- 결과물(비교 보고서): https://wogud98.github.io/ALEPH/challenge/T05/
- 소스: https://github.com/wogud98/ALEPH/tree/main/challenge/T05

## 짧은 확인 방법

1. 위치: 이 저장소의 `challenge/T05` (Node 18 이상)
2. 행동: `git clone https://github.com/wogud98/ALEPH` → `cd ALEPH` → `node challenge/T05/same-source.test.js`
3. 통과 모습: 마지막 줄 `10/10 통과`, 종료 코드 0
4. 안 될 때 모습: `FAIL  S0n …` 줄과 이유가 찍히고 마지막 줄이 `n/10 통과`(10 미만), 종료 코드 1

## 고친 버그

22:17 KST 예약 수집이 GitHub cron 지연으로 다음 날 새벽에 돌았을 때, 원천은 아직 전날 값을 주고 있었습니다(원천 갱신 시각이 같음). 수집기가 기록일을 수집 시각으로만 정해 이 값을 새 날짜 행으로 저장했고, 화면에 "전날 대비 변동 없음"이 잘못 나왔습니다. 이제 원천 갱신 시각이 직전 기록일 행과 같고 오늘 행이 없으면 새 행을 만들지 않고 로그(`skip_same_source`)와 상태만 남깁니다.

## 결과 요약

| | AI A (먼저, 인계) | AI B (이어받기, 완료) |
|---|---|---|
| 실제 작업시간 | 3분 31초 | 1분 15초 |
| 사람 요청 수 (상한 20) | 1 | 1 |
| 오류 회차 | 1 | 1 |
| 검사 통과 수 (종료 시) | 9/10 | 10/10 |
| 시작 → 종료 소스 버전 | `0be119d` → `dad1cc7` | `1d92607` → `a5ca262` |

모델·서비스 이름은 보고서의 판정 구간에서 가렸습니다. 공통 상한은 각 AI 60분, 사람 요청 20회입니다.

## 구성

| 파일 | 역할 |
|---|---|
| `TASK.md` | 작업 전에 고정한 조건: 고칠 것, 공통 상한, 두 AI에 보낸 같은 최초 요청 (고정 커밋 `56f33c6`) |
| `same-source.test.js` | 고정 검사 10개(S01~S10). 고정 뒤 삭제·완화·기대값 변경 0건 |
| `HANDOFF.md` | AI A가 남긴 7항목 인수인계 문서 (목표·현재 상태·실행 명령·통과 검사·남은 문제·다음 행동·건드리지 말 것) |
| `LOG.md` | A 시작 → A 인계 → B 시작 → B 완료 순서의 작업 기록, 인수인계 누락·재현·오류 회차 기록 |
| `index.html` | 공개 비교 보고서 (GitHub Pages) |
