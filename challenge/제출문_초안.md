## 짧은 확인 방법
1. 위치: 새 시크릿 창에서 https://USER.github.io/REPO/ 를 엽니다.
2. 행동: Tab 두 번으로 첫 번째 "상황, 행동, 결과 보기" 버튼에 이동 → Enter(또는 클릭) → 다시 Enter
3. 통과: 첫 Enter에 상황·행동·결과 세 줄이 펼쳐지고 화살표가 아래를 향하며, 두 번째 Enter에 다시 접힙니다.
4. 안 될 때: "There isn't a GitHub Pages site here" 404 화면이 나오거나, 버튼을 눌러도 아무것도 펼쳐지지 않습니다.

## 실제 결함 3개 (수정 전 → 수정 후)
1. 펼치기 버튼
   - 전: CSS의 display:grid가 hidden 속성을 덮어써서, 누르기 전부터 상황·행동·결과가 모두 펼쳐져 있고 버튼을 눌러도 화면이 바뀌지 않음
   - 후: .star[hidden] { display: none; } 추가 → 닫힌 상태로 시작하고 클릭·Enter·Space로 열고 닫힘
2. 등고선과 글자 겹침
   - 전: 장식용 등고선이 "SKT ALEPH", "ROTC 59기 임관" 설명 글자 위를 지나가 읽기 어려움 (자동 대비 검사는 SVG 선을 배경으로 인식하지 못해 통과로 나옴)
   - 후: 지도 라벨처럼 글자 둘레에 바탕색 테두리(text-shadow)를 넣어 선이 글자 앞에서 끊김
3. 1366×768 화면의 첫 화면
   - 전: 실제 브라우저 창(보이는 높이 약 657px)에서 근거 링크가 657px로 화면 끝에 걸리고, 펼치기 버튼은 705px로 스크롤해야 보임
   - 후: 세로 여백을 줄이고 큰 제목을 빼 소개 문장을 제목으로 씀 → 근거 579px, 버튼 617px로 첫 화면 안에 들어옴

최종 콘솔: 빨간 오류 0건 (배포 후 실제 브라우저에서 다시 확인)
